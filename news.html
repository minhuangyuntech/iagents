2026-07-25 · OpenClaw 官方 Commit

OpenClaw 把 before-tool-call policy pipeline 拆開，這很適合拿來教工具執行前其實有三層責任：policy 決定能不能做、approval 決定要不要問人、diagnostics 決定失敗時能不能追到真正原因。

2026-07-25 · OpenClaw Official Commit

OpenClaw splits the before-tool-call policy pipeline, which is a clean way to teach that pre-tool control has three separate responsibilities: policy decides whether a tool may run, approval decides whether a human must confirm, and diagnostics decides whether a failure is still debuggable.

A good classroom exercise is to separate every “tool denied” event into rule evaluation, approval boundary, and diagnostic evidence instead of treating before-tool-call as one opaque gate.

2026-07-25 · OpenClaw Official Commit

OpenClaw now honors deny fallback for shell-expansion execs, making it a compact fail-closed lesson: when expansion is denied, engineers need an explicit answer about whether the system aborts, falls back, or silently changes execution path.

Students can redraw the change as a small state machine that records which fallback path remains legal after denial and which path must stop immediately.

2026-07-25 · Hermes Agent Official Commit

Hermes fixes desktop slash commands so they target the user’s current chat instead of spawning a new session, which cleanly separates “the command parsed” from “the state was written back to the correct target.”

A useful verification pattern is to record not only whether the slash command ran, but also which chat actually received the resulting state change.

2026-07-25 · Hermes Agent Official Commit

Hermes relay reaches Phase 3 interactive UX by wiring approvals, confirms, clarify, and the React acknowledgement lifecycle together, which is a strong lesson that human-in-the-loop work is not just rendering a prompt but closing the full confirmation and acknowledgement loop.

A compact exercise is to map four steps for every interactive turn: who initiated the prompt, who confirmed it, when the frontend observed the ack, and where the traceable evidence lives.
