今天新增的小教學提示

release 先看 failure model

看到大型 release 時，先問 primary path 壞掉後剩哪個 recovery store 與 channel evidence，不要先被功能清單淹沒。

scope 錯誤常偽裝成 UI 小 bug

切換 session 後的模式殘留、跨 board 串資料、錯誤 retag，常常都是 scope key 放錯層級。

寫檔成功不等於資料完整

模糊取代、非 UTF-8 判斷與 symlink target preservation 都要拆開記，否則很容易把靜默破壞誤看成成功寫入。

2026-08-01 · OpenClaw Official Release

OpenClaw 2026.7.2-beta.6 bundles quarantine stores, crash-recoverable SQLite snapshots, and durable channel delivery, so the teaching question is not feature count but which state survives primary-database damage and which channels remain recoverable after restarts.

A good reading pattern is to split the release into three columns: the recovery store that survives DB damage, whether accepted messages remain recoverable across crashes, and which queued sends stay valid after rewind or branch changes.

2026-08-01 · OpenClaw Official Commit

OpenClaw fixes TUI mode scoping when switching sessions, making state scope teachable: trace, verbose, and reasoning settings should not leak from one session context into another just because the operator changed focus.

Students can separate session key, visible mode state, and actual delivery ownership; many “we switched sessions and it looked wrong” bugs are really scope-reset failures at the session boundary.

2026-08-01 · Hermes Agent Official Commit

Hermes fixes a fuzzy-match context_aware path that could silently replace half-matching wrong content, which is a crisp lesson that approximate matching is not free: without guardrails, bulk patching can corrupt files quietly.

A practical classroom table uses three columns: matching strategy, whether replace_all is actually safe, and the first wrong write you would expect if the heuristic over-matches.

2026-08-01 · Hermes Agent Official Commit

Hermes fixes file operations around non-UTF-8 data and symlink targets, reminding students that “the write succeeded” does not prove the write hit the right object; encoding mistakes and atomic-write swaps can quietly damage integrity.

Have students separate byte decoding, binary detection, and symlink-target preservation instead of summarizing it as a generic file-write bug.
