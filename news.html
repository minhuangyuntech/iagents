今日課堂提問

請每組挑 1 條 transport / reconnect 類 commit、1 條 queue / session ownership 類 commit、1 條 timeout / delivery 類 commit，再對照 1 則外部風險報導：分別標出 source of truth、failure boundary、first missing evidence。

今天新增的小教學提示

Heartbeat 要有可觀測證據

看到 reconnect 類 commit 時，不要只記「有重連」；要再追是否有 heartbeat、斷線判定與 reconnect 後第一個成功證據。

Queue 與 session ownership 分開看

背景佇列晚到時，最容易寫錯的不是內容本身，而是落錯 session；請固定記 origin session 與 final write-back target。

Timeout 不是只有一條路徑

若 commit 說修了 media timeout，請再核對 video、audio、image 與 generic upload path 是否真的共用同一套 timeout 契約。

2026-07-30 · OpenClaw Official Commit

OpenClaw adds WebSocket heartbeats and automatic reconnect for remote Codex sessions, making it a clean lesson in long-lived agent transport: it is not enough for an agent to connect once; it also has to prove the control channel is still alive and can recover state after a break.

A useful classroom exercise is to separate heartbeat, disconnect detection, reconnect condition, and the first post-reconnect evidence signal instead of treating “it connected again once” as reliability.

2026-07-30 · OpenClaw Official Commit

OpenClaw cancels realtime Discord playback under backpressure, which is a compact streaming-control lesson: when output can no longer keep up, the system needs a clear stop boundary instead of letting stale audio continue to accumulate.

Students can add three evidence columns here: who detects backpressure, where cancellation takes effect, and which residual outputs still need cleanup after the stop.

2026-07-30 · Hermes Agent Official Commit

Hermes keeps queued desktop prompts bound to their origin session, which is a strong lesson in session ownership: a delayed background prompt should not jump into a newer chat just because the user navigated away.

Ask students to separate the origin session at enqueue time, the execution session during background drain, and the final write-back target as three different state-ownership checkpoints.
